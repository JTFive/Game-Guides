    Sign in with GitHub

    The editor uses a GitHub access token to save for you. You create it once on GitHub and paste it here.

    1. Open GitHub → new fine-grained token ↗.
    2. Name it Guide editor and pick an expiration (e.g. 1 year).
    3. Under Repository access choose Only select repositories → pick this site's repo.
    4. Under Permissions → Repository permissions, set Contents to Read and write.
    5. Click Generate token, copy it and paste it below.
